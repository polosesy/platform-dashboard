## 1. 개요

이 연동이 무엇을 가능하게 하는지 3줄 이내. 지원 범위와 지원하지 않는 것.

> **5살 비유**: 한두 문장.

## 2. 동작 방식

누가(어떤 ID가) 무엇을(어떤 API를) 어떤 경로로 읽는지. 다이어그램(Mermaid) 하나.

## 3. 준비물

- 필요한 역할(어느 테넌트의 어떤 Entra 역할 / Azure 역할)
- 필요한 도구(az CLI 버전 등)
- 미리 정해야 하는 값(연결 키, 표시 이름 …)

## 4. 설정 — 자동 (권장)

ARM/Bicep 템플릿, az CLI 스크립트, Terraform 중 지원하는 것. 복사해서 실행할 수 있는 명령, 바꿔야 하는 자리표시자 표.
