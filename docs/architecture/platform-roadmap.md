# 플랫폼 고도화 방향과 백로그

2026-11-12 기준 검토 결과입니다. 기능별 설계는 각 영역 문서에 있고(보안 [security-roadmap.md](./security-roadmap.md), 메뉴 구조 [kubernetes-ia.md](./kubernetes-ia.md), 디자인 [design-system.md](./design-system.md), 멀티클라우드 [multi-cloud.md](./multi-cloud.md)), 이 문서는 **무엇을 먼저 할지**와 **남은 일 목록**만 다룹니다. 결정된 계획이 아니라 제안(초안)입니다.

> **5살 비유**: 장난감을 많이 만들었는데, 불을 켜고 직접 놀아 보지 않고 상자에 넣고 있었어요. 그래서 먼저 매번 직접 눌러 보는 로봇을 만들고, 그다음에 새 장난감을 만들어요.

### 상태 저장소 설계 (구현 전)

지금 파드 하나가 전제입니다(`replicas: 1`). 둘 이상으로 가려면 아래가 파드 사이에 같아야 합니다.

| 상태 | 지금 | 파드 2개일 때 문제 | 옮길 곳 |
|---|---|---|---|
| 이슈 상태·팀 질문·SLO 설정/초기화·팀 배치·알림 | 파드 로컬 JSON 파일(`AUD_ARRANGEMENT_DIR` 등, 없으면 메모리) + 파일별 잠금·`rev` 409 | 파드마다 다른 값, 재시작하면 사라짐(쓰기 볼륨이 없으면) | 공유 저장소(문서 = 지금 JSON 그대로) |
| 생성한 라이브 다이어그램 | 메모리(재시작 뒤 한 번 다시 생성 — `liveRestore`) | 다른 파드에 가면 404 → 다시 생성(동작은 하지만 느림) | 그대로 두고 재생성에 맡김 |
| 캐시·single-flight·백오프 | 메모리 | 파드마다 따로 읽음 = Azure 호출 2배(스로틀 위험), 값은 맞음 | 그대로(필요하면 나중에) |
| 알림 중계 '한 번만 보냄'·Grafana 가져오기 타이머 | 메모리 + 파일 | **두 파드가 같은 알림을 두 번 보냄** | 한 파드만 하도록 임대(lease) |

- **인터페이스 먼저**: 다섯 저장소가 쓰는 동작은 `read(key)`·`write(key, doc, {ifRev})`·`list(prefix)` 셋 — 파일 구현을 그 뒤로 옮기면 화면·라우트는 안 바뀝니다. 낙관적 잠금(`rev` 불일치 = 409)은 이미 있어 저장소의 조건부 쓰기(ETag)에 그대로 맞습니다.
- **저장소 후보**: Azure Blob(문서당 하나, ETag 조건부 쓰기, 워크로드 ID로 비밀 없음 — 홈 연결 신원에 그 컨테이너의 Storage Blob Data Contributor) › Kubernetes ConfigMap/Lease(추가 Azure 리소스 없음, 그러나 파드가 Kubernetes API 토큰을 가져야 해 지금의 `automountServiceAccountToken: false`를 깨뜨림) › 공유 볼륨(Azure Files — 파일 잠금이 파드 사이에 안 통함). **권장: Blob**, 임대도 Blob lease로.
- **순서**: ① 저장소 인터페이스 + 파일 구현 이전(동작 변화 없음) ② Blob 구현 + 연결 점검에 권한 행 ③ 알림 중계·가져오기 임대 ④ `replicas: 2` + PDB 조정 ⑤ 캐시 공유는 측정 뒤 결정.
- **하지 않는 것**: 데이터베이스 도입(문서 수십 개 규모), 세션 고정(sticky) 라우팅으로 때우기(재시작에 값이 사라지는 문제는 그대로).

### ① 검증·배포 기반의 내용

- 시험 계정으로 주요 화면 10여 개를 여는 브라우저 테스트를 배포 뒤 실행(화면이 뜨는지·오류 알림이 없는지·예시 워터마크가 없는지).
- `scripts/aks-test.sh deploy`: 푸시 전 이미지 `AUD_VERSION` = 빌드 태그 검사, 롤아웃 뒤 `/healthz` 버전 검사.
- 플랫폼 자신의 지표(`/metrics` — 요청 시간, Azure 호출 실패·스로틀, 캐시 적중률)와 SLO 탭 등록.

### 그 밖의 후보

- 정기 브리핑 전송(개요의 브리핑을 알림 채널로 — 중계 기능 재사용, 작음)
- 통합 검색(Ctrl+K가 화면만 찾음 → 리소스·워크로드 이름으로 패널까지)
- 팀별 보기(이슈 목록의 팀 필터를 히트맵·SLO·비용에도)
- 멀티클라우드는 요구가 생길 때까지 보류(타입 이음새만 있음)

| 쟁점 | 결론 |
|---|---|
| 새 기능 대 검증 기반 | 검증 기반 먼저 — 확인 못 한 기능이 쌓이면 신뢰를 잃고, 규모가 작음 |

## 2. 백로그

### 결정이 필요한 것

- 레지스트리 `AcrPull` 부여 여부 — 앱 런타임의 이미지 설정 읽기, 보안 로드맵 P4b(OCI 라벨)의 전제
- 시험·온프렘 환경에 `AZURE_TRANSLATOR_KEY` 설정 여부 — 없으면 문장 표에 없는 위협 탐지 경고·리소스 상태 요약은 영어로 남음
- 옛 API `/api/security/score`·`/api/security/alerts` 삭제 — 웹이 쓰지 않고, 점수가 없을 때 0/100으로 채움

### 실측·확인이 남은 것

- 앱 런타임의 Defender 이미지 스캔 경로(`softwareDetails.language`) — 스캔 결과가 있는 환경에서 필드 확인(시험 환경은 하위 평가 0건)
- 앱 런타임의 OpenTelemetry 경로 — 작업 영역에 `target_info`가 있는지
- 히트맵 Old Gen(major GC 뒤 live / 최대) 값과 Grafana 값 비교
- 2026-11-12 변경의 로그인 화면 확인: 비용 카드 문구, 위협 탐지 한국어, 앱 런타임 칩·버전, 예시 차단 안내, AKS 클러스터 '읽지 못한 종류' 알림

### 작은 미완성

- 비용 '예산 사용률' 카드: 실제 데이터에서 값을 채우는 코드가 없어 항상 '—'
- 통화: Azure가 단위를 주지 않으면 USD로 표시
- Helm 차트에 `AUD_SAMPLE_DATA` 값 없음(운영 기본 = 꺼짐이라 동작에는 문제없음)
- 예시 데이터: 카드별 '예시' 표시 없음(리본·워터마크·제목 접두사만), 예시 사건 시각이 상대 시각
- 열 · 값 구성: 팀 공유 세트, 끌어서 순서 바꾸기
- 라이브 다이어그램 수동 배치: Alt+화살표, 파일 내보내기
- 경고 문구 한국어 표: 유형 2가지(kubelet kubeconfig 접근, 중요한 볼륨 탑재)뿐 — 새 유형이 보이면 `services/alertTextsKo.ts`에 추가

### 보류 중인 큰 항목

- RED 지표 — **보류 사유 해소, 구현 여부 결정 대기**(2026-11-12 시험 환경 작업 영역 실측). 예전(11-05까지): spanmetrics 카운터가 10분에 1,000번 넘게 리셋되어 `rate()`가 약 800배로 부풀었음. 수집 파이프라인이 11-06에 고쳐진 뒤:
  - `sum by (collector)(resets(traces_spanmetrics_calls_total[10m]))` = 0, `[6h]`도 0, 수집기 하나(시계열 568개)
  - 서버 스팬(`span_kind="SPAN_KIND_SERVER"`) 11.2/s ≈ Micrometer 요청 10.9/s — 종류를 거르지 않으면 58/s(내부 스팬 46/s가 섞임)
  - 서비스 17개 = Micrometer `application` 17개, 지연 히스토그램 있음
  - 구현할 때 지킬 것: 서버 스팬만 · 리셋 검사는 수집기로 걸러서 · 라벨이 `service_name`·`span_name`·`status_code`뿐(네임스페이스·파드·HTTP 상태 코드 없음 → 워크로드 연결은 서비스 이름 일치, 오류는 스팬 상태 `STATUS_CODE_ERROR` — 5xx와 같은 뜻이 아님) · 요청의 대부분이 `/actuator`(Micrometer 기준 제외하면 0.9/s)라 스팬 이름으로 제외 · SLO 탭의 SLI는 Micrometer 그대로 두고 RED는 따로
- Hubble — Loki 드롭을 출처 선택기의 세 번째 출처로 · HTTP L7(데이터 0건) · 알려진 드롭 분류
- 라이브 다이어그램 — ExpressRoute·P2S·VNet 간 연결 · Private Link Service · 자동 크기 조정 원인(Activity Log)
- Grafana를 통한 읽기(2단계, 연결별 선택) · 기능 × 권한 카탈로그의 Graph 권한
- 디자인 시스템 — 키트로 옮기지 않은 화면
